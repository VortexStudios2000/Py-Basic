# Py-Basic
A "Compiler" that converts Python code to TI-Basic code that works on the TI-84 Plus CE Graphing Calculator
(May add additional compatibility later but the TI-84 Plus CE is the current target)

A HUGE thanks to TI-Basic Developer Wiki!!
http://tibasicdev.wikidot.com/homescreen
